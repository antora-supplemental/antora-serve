== [0.1.0]

* First standalone `@antora-supplemental/serve` release.
* `antora-serve <playbook>`: generate, HTTP serve, watch local sources, SSE live-reload.
* Improvements over the closed Antora core MR: SSE (not 1s poll), rebuild queue coalescing, `start_paths`, skip output/cache/.git, indexify static fallback, peer-deps on upstream Antora (no core fork).
